# Flutter Android 0.10.7 / Windows 0.4.16 本机测试

仅生成本机测试包：未上传更新、未推送源码、未部署服务，正式更新清单保持不变。

## 本轮修复

- 从首页、分类、排行、搜索、收藏和作者作品列表进入作品详情，返回时恢复原列表与滚动位置。页面、分类、搜索条件和页码分别保存位置，不互相覆盖。
- 顶部一级/二级分类布局保留已选分类与页码，返回详情后恢复列表位置。
- 加载占位区与真实列表独立保存滚动状态；即使禁用缓存、返回时需等待网络，数据回来后仍恢复原位置。内部轮播、网格等滚动组件与主阅读区隔离，避免覆盖纵向位置。
- 位置只保存在当前账号运行会话内存；退出或换账号会丢弃旧会话的位置。未保活隐藏页面，也不会在后台持续运行旧文章播放器。
- 聊天室以最新消息一端为滚动原点，每次进入、切换频道或重新打开时定位到最底部；浏览较早消息时收到新消息不会强行滚到底。较早历史从上方加载，回复、艾特及频道草稿继续保留。
- 动态后台更新不再无条件将阅读位置重置为零；主动刷新保持原有回到顶部的行为。

## 建议验收

1. 手机和电脑分别在首页往下浏览，点开作品后返回，确认回到刚才位置；再验证分类、周排行第二页、搜索第二页和收藏。
2. 使用顶部分类布局选择二级分类并翻页，浏览到中间，进入作品后返回，确认分类、页码和位置一致。
3. 在“我的 → 设置 → 本地缓存”关闭缓存，再重复返回测试，确认网络重新加载完成后能恢复位置。
4. 进入聊天室应看到最新消息；往上看旧消息后切换频道、离开再进入，均应定位到最新一条。停留在旧消息区收到新消息时不会被强制拉走。
