# 动态模板与浏览体验

本次新增独立的动态模板工作台。原 AI 投稿助手、工具箱与正常/源码编辑器继续使用原入口。所有改动位于共享 Flutter 工程，适用于 Android、Windows 和 macOS。

## 使用动态模板

入口为 **我的 → 创作中心 → 动态模板**。

1. 使用游戏、音声、漫画、动画或通用起始模板，或从投稿范例/须知的公开 HTTPS 链接及粘贴资料提取模板。
2. 确认模板名称、作品类型、必填字段、标题规则、段落顺序和自购证明条件。模板修改保存新版本，已存在的任务保留原版本。
3. 创建任务，通过对话提供作品链接、下载地址、提取码和修改要求；在资料页补充/修正信息并使用官网图床上传封面和自购证明。
4. 查看缺项、完整预览，然后带入原投稿编辑器。最后的官网提交由用户确认。
5. 任务对话与资料持续保存在当前账号的本机 SQLite 数据库，可恢复、导出及删除。模板与投稿摘要通过 FTS5 检索；短词使用有界子串查询，完整对话和下载密码不进入记忆索引。

网页提取只创建待确认模板建议。范例排版、官网规定和个人习惯需要人工核对；网页中的指令不会成为客户端权限。AI 完善模板和正文改写沿用已有模型配置和额度，调用失败保留原资料。

AI 完善模板使用专用 `template_refine` 协议和提示词，直接校验七字段 JSON，不借用投稿检查的返回格式。内置服务沿用原认证、额度与幂等机制；旧七个工具任务保持原提示词和行为。模板建议参考来源前 1800 字，用户可手工补充规则。

已投稿作品需要先载入官网最新版本，再继续修改；原编辑器的版本/内容指纹和编辑锁仍有效。官网已成功但未返回作品编号时，任务阻止再次新建投稿，需先核对管理列表并关联自己的作品编号。

载入官网作品时保留其发布状态和排期。完整官网正文的修改通过对话或原编辑器进行，资料页不会用简短介绍覆盖完整正文中的媒体和下载模块。

定时发布复用官网 `future` 状态，仅对具有 `publish_posts` 权限的账号开放。普通作者提交审核后的实际公开时间由官网审核决定。每个任务可保存自己的排期。

本地持久化按账号隔离，不代表跨设备同步。外部 MCP/Skill 与云端定时提交服务未在本轮开放。

## 浏览与评论

- 首页、分类作品、排行等作品列表底部支持直接输入页码。非法页码保留当前列表并提示；页数与服务器分页数据一致。
- 分类顶部收紧图标、标题与双层导航，横向滚动条和桌面滚轮继续有效。
- 楼中楼默认展示 3 条已加载回复，支持展开/收起；“查看全部回复”保留分页入口，区分已加载数量与真实总数。
- **快撸** 位于首页和分类之间，根据本机阅读足迹的分类及近期权重随机推荐，并保留一定探索内容。没有阅读偏好时使用通用作品。
- 快撸支持下拉换一批、触底自动加载，界面不显示分页。跨来源和批次去重，排除已读及非公开作品；网络失败保留当前内容。
- 新阅读足迹保存分类；旧足迹在后台补全分类并落盘，不阻塞首批推荐。切换账号丢弃旧在途结果。
- 从推荐作品返回保留列表和滚动位置。

## 维护与本机测试

- 工作台：`desktop/lib/pages/dynamic_templates.dart`。
- 模板规则：`desktop/lib/core/dynamic_templates.dart`；SQLite/FTS5：`dynamic_template_store.dart`。
- 推荐模型与分页采样：`desktop/lib/core/quick_feed.dart`；页面：`desktop/lib/pages/quick_feed.dart`。
- `state.dart` 仅增加推荐状态及分类足迹保存；`authoring.dart` 增加动态任务元数据透传和网站成功后的本机记录。
- SQLite 3.x 原生资源由依赖的 native asset hook 打包。初次交付需完整安装包，不能向未包含此资源的旧基础包直接发送 Dart 补丁。
- 本机测试构建：`python tools/build_dynamic_template_tests.py --platform windows` 或 `--platform android`。脚本使用已缓存的固定引擎，不注册发行版、不上传安装包、不修改正式更新清单。
- 测试包位于 `output/2026年10月24日/20261101-动态模板测试/`。测试补丁通道为 `local-template-test`；不向正式用户推送。
- macOS 使用相同共享代码，安装包需要在 macOS 上构建验证。
