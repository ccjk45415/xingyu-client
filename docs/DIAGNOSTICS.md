# 本机诊断信息

Android 0.9.10 / Windows 0.4.7，2026-10-22。

两端入口：我的 → 设置 → 诊断信息；未登录也可使用登录页的诊断入口。可查看、复制及清空最近10条异常。清空诊断不会清除登录信息、阅读数据或草稿。记录不自动上传，由用户自行复制后发给开发者。

只记录版本、系统/引擎信息、异常时间（UTC）、异常类型、固定操作阶段及调用位置；不记录原始异常消息、账号、密码、会话、API Key、HTTP请求/响应或投稿正文。桌面调用栈排除本机用户名与绝对路径，保留包内源文件位置或AOT代码地址。Android使用应用私有偏好，Windows使用当前用户绑定的DPAPI安全存储。Windows安全存储不可用时保留内存记录，并在面板提示。

Android保存未处理Java异常，并在下次启动提示复制；编辑器初始化失败还可在错误页面复制。Windows保存Flutter框架、Dart平台/Zone未处理异常以及通用操作异常。记录不能保证覆盖系统强制结束、断电或所有原生引擎崩溃。

用户已于本次明确授权完成后上传新安装包。Android原签名覆盖升级；Windows需完整解压，并退出旧版后运行新目录。
