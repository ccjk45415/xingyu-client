# Android 0.9.3 / Windows 0.4.2 本机测试包

状态：等待用户测试，未上传、未发布，线上仍为 Android 0.9.2 / Windows 0.4.1。

## 使用与测试

- Android：安装 output/Cangku-Xingyu-0.9.3-debug.apk，保留原应用数据。沿用原签名，versionCode 16。
- Windows：退出旧程序，完整解压 output/Xingyu-Windows-0.4.2-x64.zip，再启动其中 Xingyu.exe；不要只复制 EXE。build 9。
- 正常模式：将光标放入已有链接文字，点击“编辑/插入链接”，检查回填、修改地址、修改文字、取消、移除链接及撤销。仅修改地址时保留原有文字内的排版与其他链接属性。
- 手机：编辑包含多段文字的长正文，分别检查正常/源码模式、键盘打开/关闭；正文内可上下滚动，滚到边缘可继续滑动页面并到达保存按钮。
- Windows：正常/源码模式分别在长正文开头、中间、结尾输入中文，检查微软/搜狗输入法的候选框；正文内部滚动、页面滚动、调整窗口大小和跨不同 DPI 显示器后再输入。
