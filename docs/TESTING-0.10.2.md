# 投稿工具箱与本地缓存测试说明

当前本机测试：Flutter Android 0.10.2 (27)，Windows 0.4.11 (18)。

客户端安装包未上传，GitHub 未推送，正式更新清单仍为原生 Android 0.9.10 / Windows 0.4.7。仅为内置工具更新了兼容的服务端接口，旧翻译、聊天、私信和关注接口继续保留；部署未上传静态资源。

## 安装

- 安卓：`output/Xingyu-Android-Flutter-0.10.2-test-arm64.apk`，覆盖安装上一版 Flutter 测试应用。独立包名 `moe.cangku.reader.fluttertest`，可与原生版本共存，保留 Flutter 测试版的本机资料。Android 8+、ARM64。
- Windows：`output/Xingyu-Windows-0.4.11-x64.zip`，退出旧客户端后完整解压，运行 `Xingyu.exe`，保留 DLL 与 data 目录。
- 校验：`output/Submission-Tools-Test-SHA256SUMS.txt`。

## 入口与功能

- 投稿助手 → 投稿资料 → 完整投稿分类：完整官网目录、搜索、多选、自动添加父分类和目录刷新；作品类型不再限制可选分类。
- 投稿助手 → 自动整理作品资料：读取网页资料表与正文，来源中的字段可本机提取，AI 可进一步识别；字段附原文证据并可逐项确认。原标题保留，未知资料不自动补写。
- 新建/编辑投稿 → 投稿工具箱：作品资料、投稿前检查、一句话操作、局部处理、审核意见辅助、智能排版、翻译复核、疑似重复投稿、下载信息拆分、个人投稿习惯。手机默认显示当前工具，切换时再展开全部带文字图标；电脑完整显示网格。
- 一句话操作支持正文文字修改，以及本机移动介绍配图、清理空段落。模型修改限定已有文本段落，保留链接、图片、代码、下载模块、自购证明。
- 局部处理：先在正常/源码模式选中文字，再点击「处理选中文字」。结果不会自动提交网站，带回后可撤销。
- 疑似重复：按 RJ 与作品原名检索官网，每个关键词读取首屏候选，排除当前正在编辑的投稿；结果不是全站重复判定。
- 投稿前检查：官网规范与本机必填/占位/链接/RJ 检查，另可按需调用 AI 检查正文；提交确认仍会显示本机检查提示。
- 翻译复核：本机检查数字与图片缺失，AI 对照来源给出问题与依据；检查不直接重写译文。
- 下载拆分：本机读取分享文字中的地址、提取码和解压密码，逐条预览并生成官网 dlbox 模板；不发送给 AI，仍须核对对应关系。
- 个人投稿习惯：字号、行高、段间距，按账号保存在本机；新导入的 AI 正文采用已启用偏好，旧正文手动预览后应用。设置也有独立入口。
- 设置 → 本地缓存：统计空间、启用开关、清理。作品列表/详情/分类/作者资料/公开来源与图片持久缓存；页面短时复用，刷新绕过短时缓存，网络失败尝试旧缓存并标注。公告与发现继续实时读取，聊天/私信/安全资料不写入浏览缓存。

## 额度与资料处理

- 内置工具与翻译共用 UID 每日 3 次、共享每日 16 个处理单位；单次工具输入最多 12 KB，输出最多 2500 字，失败不自动重试。
- 自定义服务沿用本机加密配置，没有客户端每日次数额度；单次资料超过编辑器/请求容量会明确提示分次处理，不静默截断。
- 规范、数字/图片基础检查、官网检索、下载拆分和习惯均不调用模型。
- 工具修改前提供预览；图片 URL、下载模块和自购证明不作为可改写文本交给工具模型。用户补充原文应只使用公开作品资料。

## 缓存边界

- 最大约 192 MB / 1800 项，最长 30 天，按写入时间淘汰旧项目。普通页面新鲜期 5 分钟，分类 1 天，公开来源提取结果 6 小时；图片可跨启动复用。
- 网站 JSON 与来源缓存按 UID 隔离；认证失败不会回退旧缓存。切换账号和清理后，旧在途请求不能重新填充缓存。
- 清理浏览缓存保留草稿、账号、投稿习惯和阅读记录；也会清除解码图片与动态内存缓存。关闭磁盘缓存不等于清空，需点清理。
- 网络不通时只有已经缓存的页面/图片可读，未下载资料仍需联网；冷启动登录验证仍遵循现有流程。

## 建议用户验收

1. 搜索过去缺失的一级/二级/更深分类，保存后重新打开检查。
2. 提取 Steam / DLsite 来源，核对作者、社团、日期等原文证据，再导入。
3. 使用已有 RJ 与不重复原名检索，核对候选链接。
4. 正常模式选中一个词或一段，请求修正/翻译；检查其他文字、图片和链接，尝试撤销。
5. 粘贴实际退稿意见，确认未知事实仍需人工补充；检查前后对照。
6. 智能排版后检查正文、图片顺序、代码、官网模块与自购证明。
7. 粘贴多个网盘分享，核对每条提取码、密码，不要把解压密码当提取码。
8. 保存投稿习惯后重新进入，导入草稿观察样式。
9. 浏览作品和配图后重启再访问；尝试刷新及短时网络失败的缓存回退。
10. 设置清理缓存后检查空间减少，同时确认草稿与账号保留。

## 验证范围

自动回归、静态分析、签名、包结构与 Windows 原生自检记录见 `evidence/submission-tools-validation.json`。本轮 Android 16 三星实机测试由用户进行；没有自动发送生产投稿、评论或消息，没有使用真实账号执行收费/计次模型推理。线上接口只做健康与未认证拒绝测试。
