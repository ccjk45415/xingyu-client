# 签到与静默更新测试

2026-10-24 用户已批准发布这批验收基座：Android 0.12.0 (34)、Windows 0.6.0 (25)、macOS 0.2.0 (3)。安卓和 Mac 仅更改下载文件名；Windows 仅调整 ZIP 目录名、VERSION.json 和说明文字以符合旧版更新器，运行程序与测试版一致。客户端内版本文字可能保留 test 标记。

## 签到

入口为“我的 → 签到”，设置中也有“签到设置”。三个自动开关默认关闭，独立开启。

- 手动与打开应用签到：固定调用站点 `auth/me` 和 `POST user/signin`，以实时 `is_signed` 确认成功。超时、网络错误和重复调用均重新核对，不能把任意错误当成已签到。
- Android 后台：使用原生 `JobScheduler`，每约3小时由系统安排联网检查，任务可跨重启保留。需要保持登录；从最近任务划掉不会主动取消任务。系统强行停止、省电策略或代理不可用会延后执行，不能承诺准点执行。
- 云端：用户明确同意后才在独立签到服务中保存 AES-256-GCM 加密会话，UID 作为附加认证数据，不保存密码。最长7天；失效、过期或关闭时删除密文。聊天认证不会自动授权云端签到。每天有重试和全局限额，网络失败只显示未完成，不伪造签到奖励。
- 多设备关闭云端签到会关闭此账号的云端任务。退出登录会尝试关闭；离线退出无法保证撤销请求已送达，重新联网后应确认关闭状态，最迟授权到期失效。

服务端环境需要独立的 `CHECKIN_ENCRYPTION_KEY`（32字节，64位十六进制）。不要把它放进源码、客户端或日志。

## 不用安装包的更新

1. 公告、发现：复用现有实时连接，内容可以直接刷新。
2. 在线布局配置：固定白名单中的横幅高度、排序、卡片密度、入口文案和功能开关。Ed25519 签名校验、版本单调递增，无法下发任意脚本；断网时使用已验证缓存。配置有效期最长31天，发布工具默认30天，过期后回到内置默认配置。
3. Dart 补丁：Shorebird 官方引擎，静默检查、后台下载，下次完全退出进程后打开生效。不弹安装或同意对话框，不阻塞首页加载。包内资源、原生插件、权限和引擎变更仍需要安装新版。

本次正式发布沿用 Shorebird app ID `a2ada273-479d-4d7b-aab8-b02b314ac5e5`，三个基座均检查 `staging` 通道。因此该通道现在覆盖正式用户，不能再把它当成隔离测试通道：今后实验补丁须使用另一个 app ID 和测试基座，向此通道发补丁需要用户明确批准。`shorebird.yaml` 关闭默认 stable 自动检查，由应用显式指定通道。本次只上传完整安装包，不发布 Dart 补丁。

在线配置私钥只保存在本机 `.toolchain/client-config/signing-key.pem`，服务端和客户端仅含公钥。执行 `node tools/publish_client_config.mjs config.json` 生成可审阅预览，加 `--publish` 才发布。回滚需发布更高版本的旧配置，不能降版本。换一台机器需安全备份原有签名私钥；其他部署者应自行生成密钥并替换两端公钥。

## 置顶

首页和评论读取站点的 `is_sticky` 标记，优先展示并显示徽标；作者及有 `edit_others_comments` 权限者可对作品的顶层评论执行置顶/取消置顶，使用站点 `comment/updateState` 接口，服务端最终决定权限。没有权限的用户不会出现该操作。

自动化测试只使用合成身份与响应，不对真实账号执行签到或修改评论。真机联网、三星 Android 16 的后台调度以及实际站点网络可用性需用户测试。
