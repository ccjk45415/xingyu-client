# 原生投稿编辑器

Android 0.9.0、Windows 0.4.0。新建投稿默认进入正常编辑模式，可以直接输入中文、选择文字排版、上传正文图片。点击「HTML 源码」可随时查看和编辑同一篇正文，再次点击返回正常模式。

## 内容和模式切换

正文以原始 HTML 保存；正常模式通过原生文本编辑器显示文字、样式、图片与网站组件。切换模式不会将整篇内容重新序列化，也不会将图片转换为纯文本。未修改的属性、未知 HTML 和网站短代码保留。旧纯文本草稿首次打开时会安全转义为 HTML。

正常模式中的文字修改只替换选中文字对应的源码；图片和下载组件作为完整对象保留，用户可以明确选择删除。撤销、重做、本机草稿和 AI 导入继续使用同一份正文。单次编辑超过编辑器容量时明确拒绝该次输入，保留原文与选区，不自动截断。

## 图片

上传前保存插入位置，上传期间禁用编辑与重复操作；结束忙碌状态后才将网站返回的图片地址插入正文。账号、页面或正文版本变化时不把图片插到其他草稿中。失败不清空正文。

图片插入后在正常编辑区域可见。通过图片设置可替换图片、删除、修改说明、尺寸、链接及官网模糊样式。图片上传与最终投稿提交是两次独立操作，上传图片不等于发表文章。

## 官网格式与适配界面

官网当前后台地址为 `https://cangku.moe/admin/post/create`。通过只读请求核对后台脚本及接口，没有用真实账号创建测试投稿、投票或上传测试图片。

| 功能 | 正文格式与行为 |
| --- | --- |
| 下载链接 | 标题、上传时间、文件来源、提取码、解压密码，以及多组链接名称/地址；可增减链接、预览、添加百度/阿里秒传代码。保存为官网 `dlbox` 短代码。 |
| 外部链接 | 独立表单及官网支持服务列表，保存为 `[iframe]链接[/iframe]`。正常编辑器显示可编辑组件卡片，阅读时可交给系统浏览器打开。 |
| 字体与排版 | 加粗、斜体、下划线、删除线、标题、段落、列表、引用、对齐、缩进、字体、字号、行高、文字与背景色、上下标、清除格式。 |
| 插入内容 | 本机与网络图片、普通链接、表格、表情、特殊字符、分隔线、行内代码与多语言代码块。 |
| 官网扩展 | 折叠内容、彩虹文字、黑条文字、随机文件名、本人投票列表/插入/创建/修改；抽奖插入按官网管理员/编辑角色显示。 |

下载卡片字段：`title`、`time`、`info`、`from`、`link1`……。提取码与解压密码按「提取：… / 密码：…」组合。预览的「未知」只是占位，不写进空的元数据；提交需要标题和有效链接。

手机界面按功能分组、显示中文名称，表单可上下滚动。电脑使用宽屏编辑布局，预览区有独立滚动条，鼠标滚轮在预览区内只滚动预览。工具说明可查看各按钮用途。

## 预览、专注编辑与打印

电脑预览区有独立滚动条，支持滚轮；专注编辑收起投稿资料，仍保留当前正文、选区和撤销历史。Android 通过系统打印服务打印或保存 PDF；Windows 可导出经过清理的本机 HTML 文件，并选择在系统浏览器打开后使用 Ctrl+P 打印。导出使用独立副本，原投稿源码不变。

## 原生显示范围

两端不使用 WebView，也不执行网页脚本或第三方播放器。复杂 HTML 组件保留原始源码；普通表格提供原生表单编辑，合并单元格、嵌套表格等不能安全编辑的结构会明确提示保留源码，避免覆盖丢失。编辑区和完整预览的排版精度可能不同，投稿前可检查预览。

投票使用官网权限及接口，保存投票会立即写入网站，界面会说明；插入投票引用和提交正文仍由用户分别操作。不会因为打开对话框就创建投票。
