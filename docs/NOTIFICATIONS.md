# 系统通知与权限

Android 通过 JobScheduler 进行有界、只读检查，最短周期 15 分钟，实际时间由系统省电与网络策略决定。需要保持登录和通知授权；划掉最近任务不等于强行停止。强行停止会阻止调度，需重新打开应用。支持私信、聊天室艾特与回复、帖子回复、评论回复、点赞；首次同步作为基线，不补弹历史消息。忙碌聊天室分批追赶。默认不展示正文预览；开启预览后，系统通知历史可能保留文字。

后台任务仅使用本机 Android Keystore 加密的会话，读取前验证 UID，不向新增第三方推送服务上传会话。切换账号、退出登录或关闭系统通知会撤销任务及已显示通知。任务失败记录仅含状态和时间，不记录响应正文或密钥。

Windows 使用系统通知区域提醒，macOS 使用 Notification Center；需保持程序运行。最小化或切换其他应用时继续接收，完全退出后不再检查。系统专注模式、通知渠道设置仍可阻止展示。通知点击进入对应私信、频道或作品，跨账号通知不会跳转。

本次 Android 权限：联网、网络状态、开机恢复系统任务、通知、震动、安装更新。文件与图片通过系统选择器授权，无需广泛存储权限。不会提前索取相机、录音、定位、通讯录等与现有功能无关的权限；未来新增原生能力仍可能需要完整安装包更新。

Windows 的 Shorebird Flutter 3.47.7 存在 Unicode 路径初始化缺陷。本工程在创建引擎前使用固定版本导出的 updater C ABI 初始化，正确转换 UTF-16/UTF-8，读取官方配置并选择通过验证的补丁。ABI 与 SDK 固定绑定；升级引擎必须重新验证结构布局和完整补丁下载、启动及回滚，不能直接替换 DLL。未初始化时不再报告“已是最新补丁”。

更新提示按平台和构建号在本机记录一次。用户拒绝不会下载或安装，手动更新入口仍保留。历史 Windows 基础包的补丁引擎无法初始化，因此无法保证远程给旧包新增弹窗；Android/macOS 可使用适配旧基础包的 Dart 补丁。
