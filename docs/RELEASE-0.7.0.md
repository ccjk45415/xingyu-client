本次更新 **Android 0.7.0 / Windows 0.2.0**。

- 两端新增AI投稿助手：内置/自定义切换，作品链接提取，游戏、漫画/同人志、ASMR/音声、动画及其他模板；支持短介绍，不要求最低字数。
- 生成后预览并选择导入标题、正文、标签、来源封面URL。正文可追加/替换并撤销；不会自动发布投稿或上传图片。
- 自定义填写HTTPS API地址、密钥和模型，兼容Chat Completions协议；密钥在设备加密保存，直连提供商，不经过星屿服务。
- 内置模式复用仓库认证，每UID每日3次，全体共享每日16次保守预算，正文最多2500字符；服务端事务预留、并发保护、幂等恢复、固定任务与结构校验。不能保证彻底免疫提示注入，需核对来源。
- 手机投稿工具栏改为「常用 / 排版 / 插入 / 更多」四组，每个按钮直接显示图标与中文名称，长按可查看操作说明。保留所有原工具，减少常驻按钮数量。

Android使用原测试签名，可覆盖安装。Windows完整解压后运行 `Xingyu.exe`，保留DLL和data目录；当前未进行代码签名。可用客户端原有检查更新入口，或从本发布页下载APK/ZIP；SHA256见 `Release-SHA256SUMS.txt`。

详情和限制见 [AI投稿助手说明](https://github.com/ccjk45415/xingyu-client/blob/main/docs/AI_ASSISTANT.md)。复杂动态网页、登录/验证页面可能提取失败，可粘贴公开作品介绍。自定义模式不受内置次数/字数限额，仍受提供商和设备容量限制。
