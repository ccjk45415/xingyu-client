# 0.10.3 / 0.4.12 本机测试说明

Flutter Android 0.10.3 (28)，Windows 0.4.12 (19)。本轮仅本机安装包，不上传客户端、不推送 GitHub、不部署服务端，正式更新清单保持原样。

## 本轮修改

- 投稿编辑器只保留一个带文字的「AI 投稿助手」按钮，移除外面的投稿工具箱、选中文字处理、投稿检查等分散入口。
- 助手内分「资料与翻译」「编辑与检查」。切换时保留表单、来源、检索词和结果，修改既有正文会带回编辑器并支持撤销；修改待导入草稿则回到草稿预览，不直接覆盖编辑器。
- 疑似重复投稿新增「作品名 / RJ 号」输入框。自动带入当前标题和来源编号，可直接填写或修改，每行一个、最多 4 项；仅影响检索，不改标题。
- 选择检索结果可以正常关闭助手并打开作品详情，显式保留导航上下文。
- 下载信息拆分不会额外创建列表。修复删空正常模式列表后留下的空项：生成下载模块时清理空项；旧草稿预览和提交正文也做兼容处理，保留有文字、图片、可见链接、代码示例和有效嵌套内容的列表。
- 工具内的下载模块预览与编辑器一致，显示实际资源卡片。

## 安装

- 安卓：`output/Xingyu-Android-Flutter-0.10.3-test-arm64.apk`。覆盖上一版 Flutter 测试应用，保留本机账号和草稿；Android 8+、ARM64，独立测试包名不变。
- Windows：`output/Xingyu-Windows-0.4.12-x64.zip`。退出旧程序，完整解压后运行 Xingyu.exe，保留 DLL 与 data 文件夹。
- 文件校验：`output/AI-Unified-Test-SHA256SUMS.txt`。

## 请重点测试

1. 编辑器只有一个 AI 入口；在两个分区间切换，确认来源和输入不丢失。
2. 「编辑与检查 → 疑似重复投稿」直接输入 RJ 号或作品原名检索；确认原投稿标题保持不变。
3. 正文选中文字，再进入「编辑与检查 → 局部处理」；应用后检查原文和撤销。
4. 生成草稿后进入编辑与检查，应用修改后应回到草稿预览，确认导入后才进入正文。
5. 拆分下载信息后，正常模式、本机预览与最终正文均不应新增空列表圆点。旧草稿已有的空列表也应在预览/提交时清理；正常有内容的列表、图片、链接与提取码保持完整。
