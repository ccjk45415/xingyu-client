# Android 0.9.6 / Windows 0.4.5 本机测试

状态：等待用户测试，未上传更新包、未部署、未发布GitHub Release。本包包含此前待测的AI界面、官网须知辅助和编辑器修复。

## 本次变更

- DLsite作品链接自动从真实dlsite.com域名的product_id路径提取RJ号；在保留原标题的基础上追加半角[RJ号]。多个来源去重，已有相同编号不重复添加；伪装域名、网址参数中的任意链接不会冒充作品编号。没有原标题时仍需手动补充，不用RJ号编造标题。
- 在“投稿资料 → 官网规范 · 标题与分类辅助”内新增“自购资源”。默认不勾选；非自购无需证明。勾选后可上传、更换或移除一张证明图片；缺证明或取消正文导入时禁止导入该自购草稿。
- 证明上传使用现有官网登录会话、官网upload/image接口与图床，上传前可确认图片。Android复用现有图片解码/压缩，Windows复用现有图片选择/压缩；上传失败保留上次成功图片。界面提醒先遮盖邮箱和订单号等私人信息。图片不发送给内置或自定义AI，不增加AI次数。
- 导入本机正文时，自动插入“自购证明”标题与图片，放在真实下载短代码模块之前；无下载模块时先放正文末尾。追加模式下会把新增介绍也放到已有下载模块前，再放证明。仅替换客户端生成的旧证明区，不重复添加证明；代码块、注释、HTML属性中的下载示例不会当作实际下载模块。
- “作品类型”“投稿分类”使用独立左对齐标签，与边框分开，并增加展开面板顶部间距。适配宽屏与窄窗口；手机原生标签继续独立显示。
- 重新提取来源会清空旧来源的证明选图，避免把上一作品的凭证附到新稿。只取消“自购资源”时不会新增证明；已经上传的图床文件不会因取消勾选而远程删除。

## 建议测试

1. 打开AI助手，输入DLsite作品链接并提取或手动粘贴。确认原标题仍是原语言，生成后的投稿标题带正确[RJ号]；多次生成/套用格式不会重复添加相同编号。
2. 展开投稿资料，检查作品类型、投稿分类标签在输入框左上方，未与边框重叠。检查窄窗口和手机竖屏。
3. 不选自购，照常生成并导入；应不要求证明、不额外上传图片。
4. 勾选自购，未上传时点击导入，应提示需要证明。上传自己已遮盖私人信息的一张真实证明，确认官网图床上传与预览；取消选择或上传失败时不要覆盖旧图。
5. 原正文已有下载卡片时，选择正文追加并导入；在投稿编辑器和本机预览核对顺序是作品介绍、来源、自购证明、下载模块。未包含下载模块时，证明放在正文末尾，可继续插入下载卡片。
6. 上传完成后取消自购勾选再导入，新正文不应附带这次证明。重新提取新作品后需重新选证明；不会擅自从官网删除已上传图片。
