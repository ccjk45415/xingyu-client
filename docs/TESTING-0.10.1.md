# Android Flutter 0.10.1 / Windows 0.4.10 本机测试

仅生成本机测试包，不上传、不部署、不推送源码，不修改正式更新入口。

## 安装

- 安卓：`output/Xingyu-Android-Flutter-0.10.1-test-arm64.apk`，版本码 26；同一测试包名与签名，可覆盖上次的 Flutter 0.10.0 测试版，保留其本机资料。原生旧版仍独立共存。
- Windows：`output/Xingyu-Windows-0.4.10-x64.zip`，build 17；完整解压再运行，勿只替换 EXE。
- 安卓 Flutter 测试版继续不接入正式更新通道。线上仍是原生 Android 0.9.10 / Windows 0.4.7。

## 动态

- 删除「继续查找更早动态」按钮及翻页入口；滑到列表底部附近，直接在原列表追加。
- 懒加载卡片，抑制重复请求与重复作品；保留已显示的投稿与滚动位置。
- 支持下拉/按钮刷新、底部加载状态、到底提示、失败原处重试。
- 返回动态时复用短期缓存的已加载内容与位置。缓存最多 6 个作者视图，每个视图最多缓存 400 条；更长的列表仍可当次连续浏览，离开后回到最新。
- 稀疏动态没有匹配投稿时，可继续向上滑加载更早内容；没有自动无限空扫。沿用官网投稿分页筛选，不新增后台接口。
- 关注变化、退出及账号切换清空缓存，晚到的旧请求不回填。

## 我的

- 紧凑头像昵称、UID 复制与等级，横排投稿/关注/粉丝。
- 收藏、足迹、评论、私信采用横排快捷入口。
- 创作中心集中新建投稿、我的投稿、本机草稿与积分；AI 助手沿用投稿页入口。
- 通知、关注动态、设置和诊断采用紧凑列表；手机单栏，宽屏电脑双栏。
- 采用类似哔哩哔哩个人中心的信息布局，保留星屿紫粉配色与现有功能。

## 建议验收

1. 动态滑到底部多次，确认原有卡片仍在、没有新页面、没有重复投稿。
2. 打开作品再返回，确认已加载列表和位置恢复；切换作者检查各自的内容。
3. 暂时断网后触发加载，恢复网络原处重试；切换账号后确认没有旧账号内容。
4. 我的每个快捷入口、投稿、关注/粉丝、设置和诊断；长昵称、深色主题。
5. 电脑使用滚轮和滚动条加载动态，缩放窗口检查单栏/双栏布局。
