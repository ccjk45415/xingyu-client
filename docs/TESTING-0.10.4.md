# 0.10.4 / 0.4.13 本机测试说明

Flutter Android 0.10.4 (29)，Windows 0.4.13 (20)。只提供本机测试包，等待用户测试；没有上传安装包、改正式更新清单、推送 GitHub 或部署服务端。

## 修改

- 投稿与管理使用带文字、眼睛/预览图标的「查看作品」「查看草稿」按钮。手机自动换行，宽屏横向排列。
- 网站草稿、待审/退回等未公开作品使用登录会话读取，并校验当前 UID 和作者。预览标明仅作者可见，不写浏览缓存或阅读历史，不显示公开分享、收藏和评论操作。官网预览入口使用 /archives/{id}/preview；不会发布或改变状态。本机草稿仍在编辑器预览。
- 正常模式删除文本后直接清理空列表、空标题、空段落和空链接，保留未修改的 HTML 字节、图片、视频、代码示例及网站卡片。旧草稿的预览与提交也清理空结构，不再依赖正文是否有下载卡片。
- 类型识别优先使用 Steam 正式类型、DLsite work_type 代码及作品形式，覆盖游戏、漫画/同人志、音声、动画、图集、小说、音乐、软件；不靠故事中提及的配音或动画误判。不覆盖用户手动选择，未知仍保留其他，不推断汉化/版本等分类。
- Steam 接口完整保留发行日期、开发者、发行商，兼容中日英字段；重新整理可勾选导入资料。
- 提取 Steam 正文视频和商店预告（含当前 HLS/DASH），以及 DLsite 多个正文区的 video/source/lazy iframe/chobit 视频。视频不送 AI 翻译，内置与自定义翻译均按原顺序保留；内置服务器兼容原协议，无需部署。
- 正文、本机预览和 AI 草稿预览支持原生内嵌播放器，默认静音，点击播放，支持播放/暂停/进度/音量。只在点击时初始化，不调用外部浏览器或 WebView；多个视频同时只播放一个，滚出屏幕、进入后台或离开页面会暂停/释放。chobit 公开嵌入页解析为原视频流；不能取得公开直链的嵌入播放器会显示重试，不自动跳转。
- 新提取缓存使用新版键，避免继续读取旧的缺失资料。

## 安装与重点测试

安卓：`output/Xingyu-Android-Flutter-0.10.4-test-arm64.apk`，覆盖 Flutter 测试版，独立包名与原签名保持不变。Windows：`output/Xingyu-Windows-0.4.13-x64.zip`，退出旧版，完整解压后运行 Xingyu.exe；保留 DLL 与 data。两端保留现有账号和本机草稿。播放器原生库会增加包体。

1. 投稿与管理 → 草稿 → 查看草稿，确认正文正常、未被发布；换账号后不应能继续看另一账号的草稿。
2. 正常模式全选删除含标题/列表/来源链接的正文，再切到 HTML 源码与预览，确认无空列表圆点；部分删除后其余图片、下载信息和有效列表保持完整，撤销可恢复。
3. 同一 Steam / DLsite 链接重新提取，检查作品类型；Steam 自动整理应出现发行日期、开发商、发行商，未知资料不编造。
4. 生成原文或翻译草稿，确认正文图片和视频顺序完整，AI 预览、导入后的本机预览、作品阅读均可点击视频原地播放，最初静音；试打开声音、拖动、暂停、切后台、切页面。
5. 手机重点测试 Android 16 视频首次播放、退出详情/投稿时的稳定性。Windows 本轮已验证真实 Flutter 纹理和首帧；手机实机仍待用户验收。

## 验证

全量 Flutter 150 项通过、3 项既有条件测试跳过；新增 10 项针对删除空结构、正式类型、Steam 资料、多段视频保留、v2 兼容、草稿权限和手机/宽屏布局。最后补充官网视频短代码断言，相关 14 项通过。静态分析无问题。

实际公开网络提取验证 Steam 620 的三类资料、17 个预告和 DLsite RPG 类型，chobit 公开嵌入页可解析直链；没有发送账号凭据或调用收费模型。MP4/HLS 原生解码、静音、暂停/拖动测试通过；Windows 实际 release 程序的原生纹理、第一帧、静音、暂停/拖动验证通过（合成视频，无用户数据）。

APK 版本、原签名、ARM64、16 KB ZIP 对齐与所有原生 ELF 加载段校验通过；Windows 原生自检、完整运行库、包内凭据排除及正式清单未变验证通过。证据见 evidence/authoring-media-validation.json、authoring-source-live.json、native-video-validation.json、native-video-ui-validation.json、authoring-media-test-packages.json。

本轮未自动发布投稿/评论/聊天消息，没有以真实账号调用 AI 生成。移动端实际播放、具体代理/CDN 和官网保存后的视频表现请在测试包中验收。
