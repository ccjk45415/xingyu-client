# 窗口记忆、聊天室头像与应用内提醒（待用户测试）

2026-10-24。此前仅准备本地测试与补丁校验；用户随后明确要求修复旧公告重复进入首批动态并上传热更新补丁。本轮获准向现有 staging 通道发布 Dart 补丁，不上传安装包、不修改正式更新入口。

## 功能

- Windows 用 Dart FFI 调用系统已有的 GetWindowPlacement / SetWindowPlacement，保存普通窗口的位置、大小和最大化状态。最小化不覆盖之前的状态，断开显示器后由 Windows 调整完全落在屏幕外的位置。状态独立保存在应用支持目录的 `window-placement-v1.json`，不属于浏览缓存。
- 聊天室头像单击进入作者主页、长按艾特，点击名字仍可艾特。私信头像沿用进入作者主页的行为。
- 三端共享的 Dart 应用内提醒：私信、两个频道的艾特与回复、官网帖子回复、评论回复、点赞；顶部消息入口显示未读计数，横幅可关闭或点击跳转。
- 我的 → 设置 → 通知设置：总开关、各类开关、内容预览。预览默认关闭，偏好按本机账号分别保存。
- 动态分页合并后统一按卡片的 `created_at` 发布时间倒序排列；解析时间而不是直接比较日期字符串。旧置顶内容不在动态中插队，同一时间用作品 ID 稳定排序。

## 提醒边界

应用进入前台 2 秒后开始检查，随后约每 30 秒检查一次；当前聊天室已有实时连接的艾特和回复可直接触发。首次启用建立游标，不补弹全部历史记录。忙碌频道分批向前读取，保留续读位置，不因一页 30 条的限制直接跨过旧消息。

进入后台、退出登录或进程关闭后暂停。没有系统推送、锁屏通知、后台常驻服务或新增通知权限。独立私信和聊天室需要认证；官网提醒使用当前登录会话和现有 `user/notification` 的 reply/vote 分类，没有臆造官网独立艾特接口。

在对应私信或聊天室中查看消息时，不重复弹横幅；新提醒在应用提醒列表中标为本机已读。提醒列表只保留本次使用最近 60 条，不会修改官网回复和私信的已读状态；打开私信页面后仍按原有逻辑读取会话。消息正文和预览不写入提醒磁盘数据，仅持久化设置与有界游标。请求失败独立重试；暂停、设置变更和切换账号后丢弃之前的异步响应。

- 新增通知设置、手机/桌面横幅截图在 `evidence/notifications-*.png`。
- 窗口 API 在独立测试窗口中验证普通位置/尺寸、最大化、最小化忽略和屏幕外恢复；报告 `evidence/window-placement-native.json`。
- 现有 Windows 正式基座的原生文件和资源全部保留，只替换同版本 Shorebird SDK 编译的 Dart AOT，形成本地免安装测试目录。新 UI 所需 Material 字形已检查均存在于正式安装包的字体中。

- 本机 Windows 因完整 Visual Studio 工具链检测失败，改由 GitHub 官方 Windows runner 构建。Windows 和 macOS 均已通过官方 `patch --dry-run`，随后成功上传第 1 号补丁，没有使用原生或资源差异绕过参数。
- 不变更 macOS 原生窗口实现；本次窗口记忆功能只适用于 Windows。
