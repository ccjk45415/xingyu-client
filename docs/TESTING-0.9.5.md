# Android 0.9.5 / Windows 0.4.4 本机测试

状态：等待用户测试；未上传、未部署、未发布。线上继续保持原版本。本包包含此前待测的编辑器修复和官网投稿须知辅助。

## AI 投稿助手

- 统一紫色圆角卡片、功能图标和文字按钮，按添加来源、AI服务、投稿资料、确认草稿分组。额度/隐私细节可展开，主操作固定在底部，处理中显示进度与取消入口。Android使用原生控件；Windows使用Flutter组件，宽屏左右分栏，窄窗口上下排列。
- 原标题不会参与AI翻译。内置、自定义、免翻译、恢复结果均默认使用来源原标题，正文仍逐段忠实翻译，图片原样保持顺序。提取缺失的标题留空供手填，不编造作品名。
- “套用投稿格式”仅在手动点击时，根据确认资料添加投稿格式；默认草稿不会自动加前缀，也不会把原名译成中文。预览标题可以继续手动编辑。
- 导入选项仍可选择标题/正文/封面/追加或替换，分类需显式勾选，导入后仍需用户在投稿编辑器确认提交。

## 建议测试

1. 在新建或编辑投稿打开AI助手，检查手机屏幕和Windows常用窗口尺寸下卡片、图标、文字、滚动与固定底部操作。
2. 提取日文/英文作品链接；确认“原标题”正确。生成后检查“投稿标题”原语言保持不变，正文已翻译，图片顺序不变。
3. 手动粘贴时填写原标题与公开介绍；选择“正文无需翻译”可直接生成且不消耗AI次数。未填原标题时导入标题会提示补充，也可取消导入标题保留原投稿标题。
4. 如有自己的AI服务，切到自定义AI，确认密钥默认遮挡、配置保存/读取和生成正常。测试连接仍可能计入服务商费用。
5. 内置生成取消或断开后，使用恢复结果，确认仍是该次任务的原标题；当前来源编辑不会改变已开始任务的标题快照。恢复失败不会自动重新请求AI。
6. 如需要官网标题格式，先确认投稿资料，再手动点击“套用投稿格式”；原标题不会翻译。核对规范与分类后再导入草稿。
