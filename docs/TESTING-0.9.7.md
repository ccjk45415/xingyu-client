# Android 0.9.7 / Windows 0.4.6 本机测试

状态：客户端等待用户测试，未上传新安装包，未更新线上版本入口，未发布GitHub Release。新增关注接口已作为兼容扩展部署，供两端测试版使用。本包包含此前全部待测修改。

## 首页筛选

- 首页作品区增加“筛选 / 定制首页”。按真实分类目录分组，多选分类取合集；一级分类可整组选择，取消子分类时同时取消会覆盖该子类的上级选择，避免仍被上级条件包含。
- 默认浏览全部分类；清空后首页不请求作品，提示重新勾选。保存后回到第一页。使用官网category_in数组进行分页筛选，并对返回分类再次检查，保证只显示命中的作品，不只过滤原来的当前页。
- 筛选按UID保存在当前设备，手机与电脑可各自设置；只影响首页作品，不影响排行、分类、搜索、作者动态或发现/公告横幅。目录暂时无效时不退回未筛选结果；可重新选择。

## 分类排版

在 我的 → 设置 → 阅读与外观 → 分类页排版 中选择“卡片排版”或“顶部双层导航”。默认保留卡片排版。

新排版将一级、二级分类固定在作品区上方，可横向滚动切换；切换分类回第一页，作品区独立滚动。翻页不离开顶部导航。Windows返回分类时保留上次选择，640像素高的短窗口自动收起装饰留白以容纳六个导航入口，Android通过页面历史保留选择。排版偏好按账号保存在本机。

## 关注、粉丝与动态

- 新导航顺序：首页/发现、分类、排行、聊天室、动态、我的。我的新增关注/粉丝数量与列表入口，作者主页新增关注、已关注、回关、互相关注；取消关注需确认。列表可翻页、访问作者主页和回关。
- 用户已确认使用APP独立关注关系，与官网网页关系不互通。作者不必先安装APP即可被关注；粉丝行为的发起者必须通过官网会话核验UID。头像/昵称来自已验证资料或官网公开作者资料，不允许客户端选择自己冒充的UID。
- 关注、粉丝和动态复用已有认证服务，两端通过同一仓库UID同步。未认证时提示授权：临时将官网会话交给服务验证，不保存密码或会话。既有有效认证可复用。关系长期保留直到取消关注；不随7天聊天历史清理。
- 动态仅展示关注作者的新投稿，不增加文字/图片动态发布功能。顶部可切换“全部动态”与单作者，作品卡片展示头像、作者、投稿时间、标题和封面，可打开作品/作者。
- 官网当前确认支持user_id单作者筛选，未确认多作者筛选。全部动态每次按官网时间检索最多3页并严格保留关注UID、去重和按时间排序；可继续查找更早内容。选择单作者直接查询该作者。未找到时不会拿未关注作品补位，不自动轮询，不发送多作者并发扫描请求。
- 关注服务当前每UID最多关注500人，每天最多500次实际关注变更；重复请求不重复计数。认证、资料同步和整体读取仍沿用现有服务限制。

## 测试建议

1. 首页点筛选，勾一组、取消其中一个子类、保存，检查只显示选中分类，并检查下一页。再清空或全选，退出重开确认账号偏好保留。
2. 在阅读与外观切换两种分类排版。顶部模式切换一级/二级、滚动作品和翻页，确认导航仍固定在顶部；打开作品后返回检查选择。
3. 从作者主页关注一位作者；到我的→关注检查列表和数量，再到另一端以同一UID登录，认证后确认同步。关注关系不会出现在官网网页。
4. 在动态查看全部与单作者，打开作品、返回、刷新和查找更早内容。非高频投稿作者可能不在最近3页中，此时可直接选作者。
5. 用两个不同的官网账号互相关注，检查粉丝、回关、互相关注与取消关注。检查切换账号不显示上个账号的关系/筛选。
