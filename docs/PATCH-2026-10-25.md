# 2026-10-25 热更新

- Windows 点击关闭按钮时可选择退出程序或最小化到系统托盘，可记住选择。可在“我的 → 设置 → 阅读与外观”修改。
- 系统托盘提供打开窗口、立即签到和退出入口。托盘启动失败时保留窗口。
- Windows 在签到设置开启后台自动签到后，托盘运行期间每 30 秒查询官网签到状态，确认未签到后立即提交。登录、启动、恢复窗口时立即检查。网络失败退避重试，登录失效后暂停。完全退出、休眠、断网时无法执行。
- 同一账号在任一客户端点开提醒或标记已读后，其余客户端在下次同步时清除该提醒的未读标记与横幅。打开提醒列表本身不会全部标为已读。
- 离线确认先写入本机待同步队列；恢复网络后重试。跨端同步只保存通知标识，不保存消息正文。聊天室和私信使用现有的认证身份；官网回复与点赞同时使用官网已读状态。

兼容基包：Android 0.13.1+37、Windows 0.7.1+28、macOS 0.3.1+6。使用现有 staging 补丁通道；不会修改安装包更新清单或公告。

补丁下载后需完全退出并重新启动。Windows 最小化到托盘不会重新启动，可用托盘中的“退出星屿”完成退出。本次跨端已读针对应用内提醒，不撤回已经由操作系统投递的通知。

验证：224 项客户端测试通过，3 项有条件测试跳过；静态分析无问题；59 项服务端测试通过。隔离的 Windows 运行验证覆盖托盘就绪、主动清理、父进程退出清理及拒绝错误窗口归属。不使用原生代码或资源差异检查的绕过选项。
