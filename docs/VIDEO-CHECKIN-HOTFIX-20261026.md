# 文章视频与安卓后台签到修复

文章 229761 在“米莉亚 羁绊剧情-P1”下方使用的是哔哩哔哩作品页 BV1YQp16yE2M。先前验证的腾讯云 MP4 是另一段视频，不能证明这一段可播。

本次为哔哩哔哩公开视频读取分集 CID 与完整 MP4 地址，带来源请求头并尝试服务返回的备用地址。接口拒绝公开播放时显示错误，不执行页面脚本，也不携带仓库登录 Cookie。播放器在正文内显示静音首帧，滚出视口后释放资源。Windows 原生播放器已用该 BV 地址验证显示首帧、静音、播放及滚出后重载；安卓和 macOS 使用相同 Dart 解析逻辑，尚未在这两端实机验证该视频。

安卓原生后台服务从三小时周期调整为系统允许的约十五分钟周期，启用时增加首次任务，网络失败最多进行三次退避重试，随后回到周期任务。重复打开应用不重置任务；关闭功能、退出或切换账号后旧任务停止。发送签到后重新读取官方状态，避免丢失响应引起重复提交。HTTP 403/419 等暂时失败允许重试，401 提示重新登录；历史成功状态按北京时间判断日期。

安卓原生任务变更随 0.13.2 (38) 安装包交付。旧 0.13.1 (37) 的热补丁恢复安装基线的原生文件，只包含兼容的 Dart 变更，不绕过 Shorebird 原生或资源差异检查。Windows 与 macOS 原生安装版本不变。

验证：Flutter analyze 无问题；245 项 Flutter 测试通过、3 项条件跳过；八组隔离的 Java 原生服务回归通过，生产源码使用 Android API 36 编译通过。Java 回归替换系统调度、加密与网络环境，不等同于真实 Android 后台调度验收。未调用云端签到服务。

后台执行仍由 Android 调度，休眠、电池优化、无网络和强行停止应用都会影响执行时机；本次未在三星 Android 16 真机验证。
