# Flutter Android 0.10.6 / Windows 0.4.15 本机测试

仅供本机测试：未上传安装包、未推送源码、未部署服务、未修改正式更新清单。

## 本轮调整

- 首页、分类、排行、搜索、作者与公开作品详情使用账号隔离的页面快照；再次打开先显示已浏览内容，联网后台刷新。无缓存首次进入显示静态占位布局，接口返回后显示真实内容，不等待图片全部下载。
- 刷新保留页面内容和阅读滚动组件；旧路由或旧账号的迟到请求不能覆盖当前页面。断网保留可用缓存并提示；认证错误不能用缓存掩盖。
- 同参数浏览请求合并，JSON/公开图片写缓存移出展示等待链；原子文件替换允许缓存读取与后台写入并行。缓存清理按批次进行；复用图片 HTTP 连接，减少重复握手。
- 内存 JSON 与公开图片原始字节分别限制为 8 MB；磁盘沿用 192 MB/1800 项/30 天清理策略，最多每 16 次后台写入触发整理。关闭及清理缓存仍在“我的 → 设置 → 本地缓存”。
- 聊天室频道栏、连接提示、空消息卡片、回复与输入区重新排版。消息改成按可见区域构建。仓库资料同步、WebSocket 与消息历史并行，不再彼此等待；重复启动不重建已有连接。已有频道消息及未发草稿继续保留在当前登录会话内存，不写公开浏览缓存。
- 私信不再等待官网资料同步才加载消息。认证、发送确认、图片权限、频道隔离及保留期限保持现有服务规则。

## 建议测试

1. 两端分别浏览首页、分类、排行和一篇公开作品，再切走返回：上次内容应先出现，并在后台刷新；测试切换分类/排行周期/翻页不会混入旧页。
2. 暂时断网再次打开浏览过的页面，应显示本机缓存与离线提示。清理缓存后第一次打开仍需要网络，不会凭空出现尚未下载的内容。
3. 阅读长文章后刷新，检查阅读界面保留；图片与视频仍应正常显示，视频默认暂停静音。
4. 聊天室两个频道切换、返回、回复、艾特、图片、草稿以及前后台恢复。连接中可以先输入，但认证连接就绪前不发送；消息历史失败可以单独重试。
5. 换账号、退出登录及清理缓存后，确认不会显示另一账号的快照。草稿预览、评论管理、通知、聊天与私信没有加入公开磁盘快照。
