# 后台签到热补丁 · 2026-10-26

用户授权：热更新修复。仅发布 Dart 补丁，不上传完整安装包，不修改云端签到服务、更新清单或公告。

修复：
- Windows 只在明确的 HTTP 401/身份失效时暂停自动签到；403、419、临时重定向和服务不可用进入有界退避重试。
- 托盘轮询前刷新已启用的系统代理配置；网络恢复后无需切换开关或重新登录。
- 手动成功签到可恢复此前因会话失效而暂停的轮询。
- 代理刷新期间关闭开关、退出或切换账户时，不再提交签到请求。
- 手机后台成功记录按北京时间日期核验，历史记录不再显示“今日已签到”；在设置中明确原生后台任务约 3 小时调度。

范围限制：Android JobService 的 3 小时周期和失败后 jobFinished(false) 仍在原生安装包中。Dart 热补丁没有更改这些原生实现，未声称彻底修复手机关后台后的执行问题。云端签到服务未改动，也未做真实云端签到测试。

验证：全套 Flutter 测试 241 项通过、3 项条件跳过；专门签到回归 20 项通过；静态检查无问题。Android 官方补丁 dry run 已通过，桌面两端通过后再发布。

目标安装基线：Android 0.13.1+37、Windows 0.7.1+28、macOS 0.3.1+6，沿用 staging 通道；不放行 native/asset 差异。
