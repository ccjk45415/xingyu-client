# 三平台安装与更新

2026-10-27：Android 0.13.5 (41)、Windows 0.7.4 (31)、macOS 0.3.4 (9)。新增网络代理和签到成功提醒，安卓系统后台代理及通知需安装新包。

- Android：应用名称为“仓库 · 星屿”，包名 moe.cangku.reader，沿用原安卓签名。支持 Android 8+ ARM64，覆盖原 Java 客户端安装，无需卸载旧版。独立包名的 Flutter 测试版不属于原版，仍可并存。本次安装包压缩原生库，兼容原客户端 24 MiB 的更新下载限制。更新下载后校验包名、版本、SHA-256 和签名，再打开系统安装程序；首次需允许安装应用，安装须由用户确认。旧版数据保留在应用私有目录，新旧引擎使用不同存储格式，首次可能需要重新登录。
- Windows：解压完整 ZIP 后启动 Xingyu.exe。本版本起，检查更新会自动下载到临时目录，验证并准备新版；确认更新前应保存正在编辑的投稿。退出程序后辅助进程替换本目录受管理的文件、重启星屿；中途失败则恢复旧版。账号、草稿、缓存位于用户数据目录，不参与替换。程序目录需要当前用户具有写权限。早于本版的客户端仍需完成一次原有的手动解压更新流程。
- macOS：M 系列芯片，macOS 12+。PKG 双击按向导安装，DMG 可拖入“应用程序”。本版提供下载并打开 PKG 安装器功能，安装后重新打开星屿。未配置 Apple Developer ID 与公证，首次安装/打开可能需要“系统设置 → 隐私与安全性”确认。不会自动关闭 Gatekeeper、系统保护或申请管理员权限绕过系统安装器。0.1.0 测试版无自动更新入口，需要手动安装本版一次。

更新清单与下载链接使用现有 Pages 第一方域名；超过单文件限额的包拆成静态分片，由入口按顺序流式返回原始完整文件，客户端仍验证整包 SHA-256。GitHub Release 同时保留完整包和源代码。

系统通知的开启方式、后台限制和权限说明见 [通知说明](NOTIFICATIONS.md)。
