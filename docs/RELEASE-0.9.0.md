**Android 0.9.0 / Windows 0.4.0**：不写代码也能直接打字、排版和发图。

- 修复上传正文图片后没有插入正文的问题，保留上传前的插入位置，并检查账号、页面和草稿归属。
- 「HTML 源码」支持双向切换；正常模式显示文字、图片与组件，保留原始 HTML、排版和短代码。
- 下载链接模板补齐标题、上传时间、来源、提取码、解压密码、多组链接和秒传；外部链接使用独立表单及官网格式。
- 补充字体、行高、表情、特殊字符、折叠内容、彩虹/黑条、随机文件名、表格和图片设置、投票等编辑功能，按官网权限显示。
- Windows 本机预览提供独立滚动条和鼠标滚轮滚动；增加全选、专注编辑与工具说明。Android 提供系统打印/PDF，Windows 支持安全 HTML 导出后通过系统浏览器打印。

两端保持原生引擎，无 WebView；复杂结构保留源码，编辑器不执行网页播放器。手机完整 UI 与系统打印尚未真机验收，译文和投稿内容仍请自行预览核对。

进入客户端「我的 → 设置 → 检查更新」，或从本页下载。Android 可覆盖安装；Windows 退出旧程序后完整解压新版，保留 DLL 和 data 文件夹。详细说明见[投稿编辑器](https://github.com/ccjk45415/xingyu-client/blob/main/docs/EDITOR.md)，校验见 `Release-SHA256SUMS.txt`。
