# 0.10.5 / 0.4.14 本机测试说明

Flutter Android 0.10.5 (30)，Windows 0.4.14 (21)。仅本机测试，不上传安装包、不修改正式更新清单、不推送 GitHub、不部署服务端。

## 分类

- 提取来源后不再仅识别作品类型：会按实际官网目录推荐分类，带上父级，并默认勾选随草稿导入；手动确认分类也默认导入，可以取消勾选。
- 「AI 投稿助手 → 投稿资料 → 官网规范·标题与分类辅助」新增明确的「AI 自动分类」按钮。导入区的「使用已确认分类」可点击；没有分类时点击可启动分类，解决灰色禁用后无法处理的问题。
- 内置/自定义 AI 使用相同结构输出分类；内置复用已部署的 /ai/v3/task preflight 协议，无需服务端部署，与翻译共用既有额度。分类只返回目录内 ID 和依据，不改正文、标题。严格拒绝目录外、隐藏分类及未确认的版本选择。
- 作品类型明确而汉化/生肉等资源版本不明时，先选大类并显示提示，不根据商店支持语言推断下载包版本。可在资源属性中填写已确认版本，或手动勾选子类。
- 取消任务或切换账号后，过期分类结果不能覆盖新任务。保留原有导入确认和取消分类导入的选项。

## 图片

- 实际失败的三张 Steam 图片均为 AVIF；网址返回 200，问题来自解码。新增原生 libavif 解码，按文件签名识别，不依赖后缀，保留原图 URL。
- 与原有图片磁盘缓存、Flutter 解码缓存、原图查看、视频封面共用；旧缓存的 AVIF 字节可直接解码，不要求用户清缓存。
- 安卓库兼容 16 KB 内存页。对 AGP 9 下上游插件的 Java/Kotlin 重复注册类、JVM 目标和旧 compileSdk 做项目级兼容配置，未修改上游原生二进制。

## 视频

- 进入可见区域后，在正文中加载视频首帧，暂停、静音展示内容与播放器控制，替代只有黑底的占位按钮。AVIF 视频封面同样能够显示。
- 不自动播放、不跳浏览器；手动播放可控制进度和声音。
- 滚出可见区域暂停，离开约两秒后释放播放器；滚回来可重新加载静音首帧。长文章不会一次创建所有视频播放器。
- Windows 真实 release 已验证首次暂停画面、手动播放、滚出释放与返回重新加载。安卓实际网络和显示仍待用户实测。

## 安装和验收

- 手机：output/Xingyu-Android-Flutter-0.10.5-test-arm64.apk。覆盖此前 Flutter 测试应用，包名与签名不变，保留草稿和账号。
- 电脑：output/Xingyu-Windows-0.4.14-x64.zip。退出旧程序，完整解压，保留所有 DLL 和 data，运行 Xingyu.exe。
- 校验：output/Category-AVIF-Test-SHA256SUMS.txt。

1. 重新提取同一条来源，确认有分类推荐；点击 AI 自动分类，检查依据和分类结果。生成并导入草稿后，编辑器的「分类 · N」应大于 0 并包含对应上级。
2. 手动选择分类后应默认勾选导入，也可取消；取消导入分类应保留编辑器原选择。版本未知时检查大类提示，再手动选择实际子类。
3. 打开原来图片失败的草稿，验证正文图片、视频 AVIF 封面和点击原图。已有缓存可直接复用。
4. 视频滚到屏幕内应显示内容首帧与进度控制，初始暂停静音；播放、开关声音、滑走和返回均应正常。重点测试手机 Android 16。
